# AI CODER CONTEXT

This folder contains the permanent working memory anchor for AI development on URUN.

## When Starting Work, Read In This Order:

1. `system_prompt.txt` — Your constitution. The 3 Pillars + 7 Sacred Rules.
2. `../docs/SYSTEM_CONTEXT/05_QUICK_REFERENCE_CARD.md` — Daily checklist.
3. `../docs/SPECIFICATIONS/00_master_roadmap.md` — Current phase & priorities.

## The 3 Pillars (Memorize These)
1. **Local Data Stewardship** — Community owns their data. Full stop.
2. **Collective Efficiency** — System reduces costs. Surplus stays in community.
3. **Human-Centric Resilience** — Tech serves humans. Communities survive failures.

## The 7 Sacred Rules (Never Break These)
1. RLS at database level (not app logic)
2. Ledger immutable (no UPDATE/DELETE)
3. Data minimization (only necessary data)
4. Reputation deterministic (same event = same points)
5. Multi-Sig enforced (>Rp 5M needs approval)
6. Fraud detection daily (automatic reconciliation)
7. User can delete/export (right to portability)

## If Unsure About Anything:
→ Default answer is **NO** until you verify against the Pillars & Rules.
→ Ask before implementing, not after.
